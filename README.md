# Linear Regression Weight Prediction
This is a beginner Machine Learning project using Python

## About
This project uses Linear Regression to predict a person's weight based on:
- Height
- BMI

## Technologies Used
- Python
- NumPy
- Scikit-learn

## How It Works
The model is trained using sample height, BMI and weight data.
Then it predicts the weight of an unknown person using their height and BMI.

## Example Input
Height: 186 cm
BMI: 22.3

## Model
Linear Regression

## Note
This project is created for learning and practicing Machine Learning concepts.
